# AI Use Disclosure

## Summary
This project's own code was generated by AI models under continuous
human direction. Hand-written changes are limited to small edits.

## Human contribution
- Overall architecture, module decomposition and interface design
- Iterative specification and refinement over thousands of interactions
- Selection, rejection and restructuring of generated output
- Review, testing and integration decisions

## Provenance and third-party code
First-party code only; dependencies are checked against the inbound
licence policy (ADR 0001). The generated code has not been scanned for
similarity to public code; report concerns through this repository's
private vulnerability reporting (Security tab) or an issue labelled
`provenance`.
